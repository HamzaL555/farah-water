# HİSSƏ 1: TELEFONA QURAŞDIRMA

**Bir dəfə — həyatınız boyu.**

1. `C:\Users\user\Desktop\Farah\release\Farah-1.0.0-release.apk` faylını telefona köçürün
   (USB, WhatsApp, Telegram, e-poçt — fərq etməz)
2. Telefonda fayla toxunun
3. Android "Bu fayl mənbəyi ilə bağlı deyil" deyəcək → **"İcazə ver"** / "Settings" → **"Allow from this source"** → **OK**
4. **"Install"** / "Quraşdır" basın
5. "App installed" çıxacaq → **"Open"** / "Aç"

Telefonda "Farah" adlı proqram görünəcək. Onu açın.

> **Qeyd:** Bu mesaj hər dəfə çıxsa normaldır — Android təhlükəsizlik üçün belə edir.

# HİSSƏ 3: İLK İŞÇİNİ YARATMAQ

Sistem boşdır — əvvəlcə işçi yaratmalısınız.

1. **Admin panel → İşçilər** (aşağıdakı menyudan)
2. **"Yeni işçi"** düyməsi (sağ altda)
3. Doldurun:
   - **Ad və soyad** — real ad (məs. Rəşad İsmayılov)
   - **İstifadəçi adı** — ingilis hərfləri ilə (məs. `rashad`)
   - **Telefon** — işçinin nömrəsi
4. **Şifrə xanasını BOŞ qoyun** — sistem özü yaradacaq
5. **"İşçi yarat"** basın
6. Ekranda **müvəqqəti şifrə** görünəcək — **bu bir dəfə göstərilir!**

**Bu şifrəni işçiyə göndərin.** O ilk daxil olmada öz şifrəsini dəyişəcək.

Hər işçi üçün **eyni addımları təkrarlayın.**

# HİSSƏ 4: İLK BIDONLAR

Bidonlar anbardan başlayır.

1. **Anbar → "Anbara qəbul"**
2. Su şirkətə gələn bidonların sayını yazın (məs. 500)
3. **Təsdiqlə** → anbar xaritasında 500 görünəcək

2. **Anbar → "İşçiyə təhvil"**
3. İşçini seçin
4. Veriləcək bidon sayını yazın (məs. 100)
5. **Təsdiqlə** → həmin işçinin "əlində" 100 bidon görünəcək

Hər işçiyə ehtiyacı qədər verin.

**İndi işçilər işləyə bilər.**

# HİSSƏ 5: İŞÇİ NECƏ İŞLƏYİR

İşçi öz telefonunda eyni APK-nı açır, öz hesabı ilə daxil olur.

### 1. Yeni çatdırılma

- **"Yeni çatdırılma"** → **"Müştəri axtar"** yazın
  - Müştəri tapıldısa → adına toxunun (seçilir)
  - Tapılmadısa → **adını və ünvanını özünüz yazın**
- **Bidon sayı** — məs. 10
- **Bir bidonun qiyməti** — məs. 2.00
- **Ödənilən məbləğ** — müştəri nə veribsə
- Aşağıda **ümumi məbləğ**, **qalan borc** və **status** avtomatik göstərilir
- **"Çatdırılmanı yadda saxla"**

> **Vacib:** O xanalardakı hesablamalar yalnız önizlədir. **Server** yekun rəqəmi yenidən hesablayır və saxlanan odur. Unudub fərqli yazsanız, sistem düzgün rəqəmi saxlayacaq.

### 2. Ödəniş gələndə

- **Çatdırılmalar → Tarixçə** → həmin çatdırılmanı tapın → açın
- **"Ödəniş əlavə et"**
- Məbləğı yazın → **Təsdiqlə**
- Borc azalır, status dəyişir

Məsələn: 20 AZN borc → 12 gəldi → borc 8 oldu, status "Qismən ödənilib"

### 3. Bidonlar

- **"Bidonlar"** → əlindəki say
- Satılmayan qalanı: **"Anbara qaytar"**
- Qırılan/ itən: **"Zədələnmiş / itmiş"**

### 4. Borclar

- **"Borc"** → kimin nə borcu var
- Müştəri → öz tarixçəsi

# HİSSƏ 6: ADMIN NECƏ İDARƏ EDİR

| Ekran | Nə üçün |
|---|---|
| **Dashboard** | Gündəlik rəqəmlər. "Faktiki alınan pul" və "Faktura" **ayrı** göstərilir |
| **İşçilər** | İşçi yaratmaq, deaktiv etmək, şifrə sıfırlamaq, hər işçinin rəqəmləri |
| **Borclar** | Kim nə borcludur, filtri, axtarış |
| **Gəlirlər** | Gəlirlər üslub (nağd/kart) və işçi üzrə bölünürdür |
| **Çatdırılma** | Bütün çatdırılmalar, istəyə görə süzülür |
| **Anbar** | Anbar qalığı, hər işçinin əlindəki say, inventar tarixçəsi |
| **Hesabat** | Günlük/aylıq hesabat, **CSV və PDF ixrac** |
| **Audit** | Kim nəyi nə vaxt dəyişib — bütün izlər |

### Dəyişiklik etmək istəyirsinizsə

- **Borc güzəşti** → Çatdırılma → aç → **"Borc düzəlişi"**
  ⚠️ Güzəşti **gəlir sayılmır** — pul gəlmiş kimi göstərilmir
- **Ödənişi geri qaytarmaq** (səhv daxil edilib) → Çatdırılma → **"Geri qaytar"**
  Ödəniş silinmir, "geri qaytarıldı" kimi qalır, borc düzgün hesablanır
- **Çatdırılmanı ləğv etmək** → Çatdırılma → **"Ləğv et"**
  (yalnız ödəniş alınmamış çatdırılma ləğv edilə bilər)

# HİSSƏ 8: DƏYİŞİKLİK ETMƏK

## Yalnız APK-nı dəyişmək

Telefon ekranındakı bir şeyi dəyişmək istəyirsinizsə:

1. Kompüterdə faylı açın:
   `C:\Users\user\Desktop\Farah\mobile\src\`
2. Dəyişmək istədiyiniz ekranı tapın (`screens` qovluğunda)
3. Dəyişikliyi edin
4. Yeni APK qurun:

```powershell
cd C:\Users\user\Desktop\Farah\mobile
npm.cmd run build:apk:release
```

5. Nəticə:
   `mobile\android\app\build\outputs\apk\release\app-release.apk`
6. Bunu `release\` qovluğuna köçürüb telefona atın

**Təxminən 2 dəqiqə çəkir.**

> Bunu edə bilmirsinizsə — mənə deyin, mən edim.

# HİSSƏ 10: MÜHİMM QAYDALAR

1. **"Ödənilib" düyməsi borcu silmir.** Borc yalnız real ödəniş qeydə alınanda azalır.
2. **Gəlir = faktiki alınan pul.** Ödənilməmiş borc gəlir sayılmır.
3. **Heç bir maliyyə qeydi silinmir.** Səhv varsa — geri qaytarılır və ya düzəliş yazılır.
4. **Anbar mənfi ola bilmir.** Kifayət qədər yoxdursa, sistem xəta verir.
5. **Hər şey tarixçədə qalır** — audit jurnalında görünür.
